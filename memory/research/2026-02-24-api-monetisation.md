# 2026-02-24 - API Monetisation & Developer Tools Research

## Research Focus: Tuesday - API Monetisation & Developer Tools

### Key Findings (February 2026)

#### 1. MCP Gateway - Emerging Major Opportunity 🔥

**Background:**
- Model Context Protocol (MCP) launched by Anthropic in November 2024
- OpenAI announced full MCP support in March 2026 (CEO Sam Altman)
- Industry shift: 55% → 78% enterprise AI adoption in one year
- GenAI usage: 33% → 71% (2023-2024)

**What is an MCP Gateway?**
- Infrastructure layer sitting in front of MCP servers
- Single, secure entry point for AI clients
- Handles authentication, routing, policy enforcement
- Acts as reverse proxy and management layer

**Core Features:**
1. Unified Access Point - One endpoint for all MCP traffic
2. Enterprise Security & Zero Trust - OAuth 2.0, OIDC, SAML
3. Intelligent Routing & Session Management - Tool-based routing, load balancing
4. Dynamic Tool Registry & Discovery - Auto-registration, version management
5. Operations & Observability - Metrics, logging, tracing

**Market Leaders:**
- Kong Enterprise MCP Gateway
- Tyk API Monetization platform
- RapidAPI (acquired by Nokia)

**Opportunity:** Build MCP-related services, converters, or management tools

---

#### 2. API Monetisation Models That Work

**Popular Models (2026):**

1. **Usage-based pricing** - Per request, per compute, per data transfer
2. **Tiered subscriptions** - Free → Pro → Enterprise
3. **Freemium + upsell** - Free API calls, paid for limits/features
4. **Marketplace models** - API aggregators taking a cut (RapidAPI)
5. **Agent-first APIs** - APIs designed for AI agent discovery/purchase

**Platforms Enabling Monetisation:**
- **Stripe Agentic Commerce** (Dec 2025) - Selling products/services to AI agents
- **Tyk** - Multi-tier plans, rate limiting, quotas, Stripe integration
- **Kong** - Enterprise API management with monetization

#### 3. Developer Tools Market Trends

**Major Shift (2026):**
- Gitpod rebranded to **Ona** (Sept 2025) - "AI software engineers for enterprise"
- Move from "code assistants" to full "AI software engineers"
- "Software conductor" role emerging

**Trending Categories:**
1. **AI Agent Infrastructure** - Coding agent sandboxes, agent hosting
2. **AI Observability** - Monitoring LLM infrastructure performance
3. **Self-Healing Docs** - AI-generated documentation
4. **API Security for AI** - Agents need secure API access
5. **MCP Servers & Gateways** - New infrastructure category

**Key Insight:** AI agents are spreading rapidly, but infrastructure to support them is lacking. This creates opportunities for:
- MCP server hosting/management
- AI gateway services
- Developer tooling for AI agents

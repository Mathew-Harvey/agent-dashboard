## Lessons Learned
- AgentMail API uses Python SDK, not REST endpoints directly (404s on raw curl)
- `from` is a Python reserved word - can't use `m.from` in f-strings, use `m.from_`
- Git commit in heartbeat needs `--allow-empty` to avoid errors when nothing changed
- Prisma generate must run before TypeScript compilation in CI
- SQLite migration lock file conflicts with Postgres - use `db push` instead of `migrate deploy`

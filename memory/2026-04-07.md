### Technical Lessons Learned

**1. AgentMail API quirk:**
- `body` field doesn't work - always null in emails
- Must use `text` field for plain text email body
- Attachments require base64 encoding with `content` + `contentType` + `encoding` fields

**2. Job site scraping challenges:**
- Most major sites (Seek, Indeed, LinkedIn) have anti-bot protection
- Seek login requires verification code from email - complex multi-step flow with SPA navigation
- Puppeteer needs realistic user agent and timing delays
- Chrome remote debugging (port 9222) works better than headless for avoiding detection

**3. PDF vs DOCX:**
- Initially used PDFKit for PDFs
- Switched to `docx` library for Google Docs format per Mat's preference
- .docx files are editable (better for customization)
- Used `Packer.toBuffer()` to generate .docx binaries

**4. Systemd vs Cron:**
- Mat's machine has no crontab installed
- Used systemd user timers instead
- Timers in `~/.config/systemd/user/`
- Enabled with `systemctl --user enable --now <timer>`

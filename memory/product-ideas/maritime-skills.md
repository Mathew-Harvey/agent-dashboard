# Maritime Skills for ClawHub

> Build and publish OpenClaw skills for the maritime industry

## Strategy
- First-mover advantage: no marine skills currently on ClawHub
- Leverage Mat's domain expertise (biofouling, ROV ops, vessel compliance)
- Create skills that help maritime operators

## Potential Skills to Build

### Tier 1: High Value
1. **Vessel Tracker** - Monitor vessel locations, schedules, maintenance due dates
2. **Hull Cleaning Scheduler** - Track hull cleaning intervals, biofouling alerts
3. **Compliance Checker** - Verify vessel compliance with maritime regulations
4. **ROV Inspection Report** - Generate reports from ROV inspection data

### Tier 2: Medium Value
5. **Port Directory** - Australian ports, contacts, services
6. **Weather Router** - Marine weather forecasts for voyage planning
7. **Parts Inventory** - Track marine parts, reorder alerts

### Tier 3: Nice to Have
8. **Fuel Calculator** - Fuel consumption estimates
9. **Crew Log** - Crew hours, certifications
10. **Incident Reporter** - Log and report maritime incidents

## Revenue Model
- Free basic skills (build user base)
- Premium skills: $9-29/month
- Bundle: "Maritime Pack" $49/month

## First Skill: Vessel Maintenance Tracker
- Build as MVP for both our product AND a ClawHub skill
- Test demand on marketplace
- Iterate based on feedback

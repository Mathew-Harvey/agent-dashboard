# Website Rebuild Outreach - Value First

## The Model
1. **Find** → Local businesses with outdated/simple websites
2. **Build** → Rebuild it better (modern, fast, mobile-friendly)
3. **Offer** → "I rebuilt your site as a portfolio piece. Want me to set you up with the real version?"
   - OR: "I liked your business, here's a modern site I made. Want to hire me?"

## Core Philosophy
- **Provide value first** — give them something useful before asking for money
- **Portfolio over pitch** — show, don't tell
- **Low pressure** — they're getting a free website either way

## Target Businesses
- Perth/Mandurah local businesses
- Mobile mechanics, tradies, cafes, salons
- Businesses that clearly haven't updated since 2010

# Website Rebuild Outreach - Value First

## The Model
1. **Find** → Local businesses with outdated/simple websites
2. **Build** → Rebuild it better (modern, fast, mobile-friendly)
3. **Offer** → "I rebuilt your site as a portfolio piece. Want me to set you up with the real version?"
   - OR: "I liked your business, here's a modern site I made. Want to hire me?"

## Core Philosophy
- **Provide value first** — give them something useful before asking for money
- **Portfolio over pitch** — show, don't tell
- **Low pressure** — they're getting a free website either way

## Target Businesses
- Perth/Mandurah local businesses
- Mobile mechanics, tradies, cafes, salons
- Businesses that clearly haven't updated since 2010

## Email Template

**Subject:** I rebuilt your website (free portfolio project)

Hi [Name],

I recently came across [Business Name] and noticed your website could use a refresh. As part of my portfolio, I rebuilt it with a modern design — faster, mobile-friendly, and with a cleaner look.

Preview it here: [link to GitHub Pages]
Source code: [link to GitHub repo]

I'm not selling anything — this was a learning project. But if you ever want a professional website for your business, I'd love to chat. No pressure either way.

Either way, you're welcome to use the rebuilt version if you like it!

Cheers,
[Your name]

---

## Workflow

1. **Hustler** finds targets + verifies website exists
2. **Coder** rebuilds (1-2 hours per site)
3. **Jeff** sends outreach email

## Pricing (if they want the real version)
- Basic: $500 (5-page site)
- Premium: $1,500 (with contact forms, gallery, etc)
- Ongoing: $100/month maintenance

## Success Metrics
- 1 out of 10 replies positively
- Build portfolio of 5-10 rebuilt sites
- Convert 1-2 into paid clients

## GitHub Issues (openclaw/openclaw)

### Critical Issue #23307 (Feb 22, 2026)
- **Title**: Config migration resolves ${ENV_VAR} to plaintext
- **Severity**: Security bug
- **Problem**: On upgrade, env var references in openclaw.json get resolved to plaintext values
- **Impact**: Credentials written in plaintext to config file
- **Affected versions**: 2026.2.19-2 → 2026.2.21-2
- **Action needed**: Check current config for exposed credentials

### Issue #23303
- **Title**: Background exec sessions killed after ~30 minutes (SIGTERM on compaction)
- **Problem**: Long-running background processes die during context compaction
- **Impact**: Batch jobs (Whisper transcription, polling loops) get killed
- **Workaround**: Use fully detached `nohup` processes (loses tool integration)
